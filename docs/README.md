# docs/

| File | What it is |
|---|---|
| `comparison.csv` | The final table of all seven models (made by notebook 07). |
| `f1.png`, `ms_per_text.png`, `f1_vs_size.png` | Comparison charts (notebook 07). |
| `<model>.json` | Test results of one model: accuracy, precision, recall, F1, size, speed. |
| `<model>-validation.json` | Best validation F1 and size. The API uses these to choose the default model. |
| `<model>-matrix.png` | Test confusion matrix. |
| `<model>-lime-correct.png`, `<model>-lime-wrong.png` | LIME explanations. |
| `class-balance.png`, `answer-length.png` | Data exploration (notebook 00). |
| `bonus-lora.csv` | LoRA vs full fine-tuning (notebook 01). |
| `api-check.json` | Every API request we tested and its response. |
| `images/` | Screenshots of the live client and Swagger. |
